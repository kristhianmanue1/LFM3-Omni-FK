0118 entre fallos; nunca usar este contrato para ejecutar efectos externos.
0119 
0120 Salida: 202 con job_id/state/status_url; GET sólo para su proyecto;
0121 admisión sólo tras persistir job e idempotencia atómicamente. Si se pierde
0122 202 o conexión después de ese punto, el job continúa; repetir POST con
0123 misma clave/cuerpo recupera el mismo id. Antes del commit durable no existe
0124 admisión: el reintento puede crear un único job. GET desconectado no cancela.
0125 DELETE responde estado de la operación y del job objetivo por separado,
0126 según cancel del contrato general; aceptación no acredita cómputo detenido.
0127 resultado con contrato general. Retención propuesta resultado 1 h tras
0128 terminal y tombstone idempotencia 24 h; caducado 410 para dueño, ajeno 404.
0129 Persistencia cifra resultados y controla accesos; registrar borrado.
0130 No crear jobs persistentes si falta almacenamiento/retención aceptados.
0131 
0132 Estados: queued -> running -> succeeded/failed/cancellation_pending;
0133 cancellation_pending -> cancelled/failed. Estado expirado después de TTL.
0134 Reinicio: queued recuperable una vez; running pasa failed con outcome
0135 unknown y no se repite automáticamente. Reclamo atómico impide dos workers.
0136 Especificar durabilidad real y recuperación antes de activarlo.
0137 Límites candidatos: 60 s de cola, 600 s procesamiento, salida <=4096 tokens,
0138 cola global 8, un job pendiente por proyecto, máximo global 1 ejecutando.
0139 Presupuesto de cola/inferencia compartido con H/M; definir prioridad justa
0140 para no dejar sin servicio las llamadas interactivas.
0141 
0142 ## Matriz obligatoria de conformidad
0143 
0144 Cada perfil tiene tests de credencial revocada, identidad suplantada,
0145 entrada inválida, límites, cuota, cancelación, backend caído, resultado
0146 truncado y datos A/B. Pruebas cruzadas H/M verifican cuota única.
0147 W/D/J añaden sus casos específicos. Ningún perfil puede anunciarse activo
