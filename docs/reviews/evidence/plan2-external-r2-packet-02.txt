0048 los campos ni los límites del v1 histórico. Puertos/domino se fijan en I2.

0055 Tools candidatas health/infer_text/infer_vision/capabilities; cancelación

0058 notificación por id JSON-RPC en stdio legado o cierre del stream HTTP en

0108 ## D — Dispositivos y robots, I4
0109 
0110 Entrada propuesta de adaptador sobre H: device_id derivado de credencial,
0111 observation_id:string (1..64), observed_at:UTC, expires_at:UTC,
0112 image o prompt y lista acotada de tipos de propuesta permitidos.
0113 Salida: observation_id, request_id, model_revision, complete,
0114 proposal:{kind,payload} y expires_at. Esquema por tarea autorizado.
0115 No generar confidence como garantía si no existe calibración independiente.
0116 
0117 Errores: observación caducada, dispositivo revocado, reloj fuera de margen,
0118 propuesta no permitida o salida incompleta: descartar sin actuar.
0119 Margen temporal candidato 2 s; no habilitar si sincronización no se prueba.
0120 
0121 Invariantes: integración inicial sólo simulador, sin actuadores.
0122 Controlador independiente valida estado físico, vigencia y permisos antes
0123 de cualquier acción. La parada local y control de seguridad no dependen
0124 de red/modelo. Una solicitud repetida no debe duplicar acción física;
0125 correlación y deduplicación pertenecen al controlador, no a la inferencia.
0126 El robot puede leer la escena después de enviar: nunca aplicar propuesta
0127 caducada por el simple orden de llegada de respuestas.
0128 Compatibilidad: cambios en acciones o payload exigen perfil versionado.
0129 
0130 ## J — Trabajos largos, I5
0131 
0132 Entrada: POST /jobs con operación admitida y límites I5; Idempotency-Key
0133 ASCII 1..64. GET /jobs/{id}; DELETE /jobs/{id} solicita cancelación.
0134 Scope jobs:create/read/cancel más scope de operación; id aleatorio opaco.
0135 La identidad y clave forman namespace; mismo cuerpo devuelve mismo job,
0136 cuerpo distinto con misma clave produce 409. No promete exactly-once
0137 entre fallos; nunca usar este contrato para ejecutar efectos externos.
0138 Comparar digest de operación+payload normalizado con defaults, sin campos
0139 de correlación/credenciales, canonicalizado por RFC 8785
0140 (https://www.rfc-editor.org/rfc/rfc8785). Rechazar claves
0141 JSON duplicadas y números no finitos. SPEC-JOBS fija librería/version y
0142 fixtures de orden de claves, tipos y defaults; no hash de bytes crudos.
0143 
0144 Salida: 202 con job_id/state/status_url; GET sólo para su proyecto;
0145 admisión sólo tras persistir job e idempotencia atómicamente. Si se pierde
0146 202 o conexión después de ese punto, el job continúa; repetir POST con
0147 misma clave/cuerpo recupera el mismo id. Antes del commit durable no existe
0148 admisión: el reintento puede crear un único job. GET desconectado no cancela.
0149 DELETE responde estado de la operación y del job objetivo por separado,
0150 según cancel del contrato general; aceptación no acredita cómputo detenido.
0151 El resultado se entrega en el envelope del contrato general.
0152 Retención propuesta resultado 1 h tras
0153 terminal y tombstone idempotencia 24 h; caducado 410 para dueño, ajeno 404.
0154 Persistencia cifra resultados y controla accesos; registrar borrado.
0155 No crear jobs persistentes si falta almacenamiento/retención aceptados.
0156 Tras vencer tombstone, reutilizar una clave crea un nuevo job_id y puede
0157 repetir inferencia; el cliente debe tratarla como nueva solicitud. No se
0158 ofrece deduplicación más allá de 24 h; ejemplos deben mostrar esa ventana.
0159 
0160 Estados: queued -> running -> succeeded/failed/cancellation_pending;
0161 cancellation_pending -> cancelled/failed. Estado expirado después de TTL.
0162 Reinicio: queued recuperable una vez; running pasa failed con outcome
0163 unknown y no se repite automáticamente. Reclamo atómico impide dos workers.
0164 Especificar durabilidad real y recuperación antes de activarlo.
0165 Límites candidatos: 60 s de cola, 600 s procesamiento, salida <=4096 tokens,
0166 cola global 8, un job pendiente por proyecto, máximo global 1 ejecutando.
0167 Presupuesto de cola/inferencia compartido con H/M; definir prioridad justa
0168 para no dejar sin servicio las llamadas interactivas.
0169 
0170 ## Matriz obligatoria de conformidad
0171 
0172 Cada perfil tiene tests de credencial revocada, identidad suplantada,
0173 entrada inválida, límites, cuota, cancelación, backend caído, resultado
0174 truncado y datos A/B. Pruebas cruzadas H/M verifican cuota única.
0175 W/D/J añaden sus casos específicos. Ningún perfil puede anunciarse activo
0176 antes de tener prueba real con un consumidor representativo y rollback.
