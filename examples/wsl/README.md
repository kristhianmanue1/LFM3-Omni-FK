# Pruebas exploratorias WSL

Versiones conservadas de las pruebas del Dell G7 7700.
Requisitos, consentimiento, límites y siguiente trabajo:
[retomar Dell G7](../../docs/retomar-dell-g7.md).

Usan el runtime fijado por `scripts/install_wsl.py` y el motor 8091.
No requieren paquetes Python externos. Importarlos no abre dispositivos.
Ejecutarlos requiere `LFM3_CONSENTIMIENTO_D09=si`.

No guardan medios ni transcripciones. La conservación de texto para
próximas pruebas está autorizada en D-10 y pendiente de implementación.
Completarla antes de iniciar nuevas verificaciones personales.
